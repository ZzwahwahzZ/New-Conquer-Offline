# Items and Resources Asset Library

Reserved runtime root for 3D loot drops and inventory icon sources.

Planned groups: gold piles, treasure chests, upgrade gems/meteors, quest scrolls, Jiang Hu resources, 21 gem families and +1 to +12/Elite equipment glow tiers.

Only verified, redistributable source files should be added. Keep 3D meshes, PBR maps and UI icon atlases in separate subfolders.
