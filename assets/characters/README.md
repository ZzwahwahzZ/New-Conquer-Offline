# Character Asset Library

Reserved runtime root for licensed, rigged GLB characters and NPCs.

Required groups: six playable archetypes, Oriental Assassin dual-dagger and archer/bow variants, merchants, blacksmith, pharmacist, banker and quest NPCs.

No character pack is represented as installed until the GLB files, animation clips, license and import validation report are committed here. Prefer CC0/MIT sources and retain attribution where required.
