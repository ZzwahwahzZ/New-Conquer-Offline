# Wuxia Imperial Pack — Asset Credits & License Register

This register is regenerated by `tools/generate_wuxia_credits.py` from the downloaded asset manifests. Only files actually downloaded, validated and included in the Wuxia pack are recorded as included assets.

## Accepted license policy

- **CC0 1.0** is accepted for commercial use, modification and redistribution.
- **CC BY 4.0** is accepted when the creator, exact asset title, source URL and license URL are retained, and changes are disclosed.
- CC BY-SA, NC, ND, custom restricted licenses and unclear license records are not automatically accepted.
- Every included file must retain source, creator, license, byte count and SHA-256 in its manifest.

## CC-BY source handling

The download and attribution pipeline accepts CC-BY when the source API supplies a verified license and creator record. No Sketchfab or OpenGameArt model is represented as included until its actual file, license and author metadata have been downloaded and validated. No guessed or placeholder creator credits are used.

## Automatic updates

The CI pipeline downloads and validates the assets, regenerates this file from manifests, and commits any credit changes back to the current feature branch. CC-BY attributions become included credits only after the actual files are present.
